# Exercício ES6+

Array de objetos com nome e nota de alunos e uma função que retorna apenas
os alunos com nota maior ou igual a 6.

Usa arrow functions, `filter`, `map`, `reduce`, desestruturação, spread e rest.

## Como rodar
```bash
node src/index.js
```

## Babel (opcional)
```bash
npm install
npm run build   # gera a pasta dist com o código transpilado
```
